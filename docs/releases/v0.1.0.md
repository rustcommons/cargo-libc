# cargo-libc 0.1.0

Build and inspect Rust programs for an older x86-64 Linux glibc release.

Original crates.io publication: 2026-10-13 (UTC). Package `cargo-libc` 0.1.0
is available and non-yanked, checked 2026-11-02. Source tag `v0.1.0`:
`ce9a7d51122f143091050d9e53b1222b77e67de1`.
These notes were reconstructed on 2026-11-02; their later GitHub publication date
is documentation backfill, not the original software release date. They were not
present at the historical tag and do not modify its package.

## Changes

- First crates.io release of `cargo-libc`, installing `cargo-libc`, `libc-linker`,
  `libc-runner`, `libc-cc` and `libc-cxx` together.
- Select glibc 2.17–2.44 through generated providers or an explicit sysroot;
  target flags leave host build scripts and procedural macros native.
- Cargo commands, ELF requirement inspection, target C/CMake wrappers and
  kernel simulation are exposed through the Cargo subcommand. Target C++ is refused.

## Upgrade

Install all five sibling executables with `cargo install cargo-libc --version 0.1.0 --locked`.
Requires an x86-64 Linux build host, Rust 1.90+, Clang, GCC and binutils.
The packaged lock selects the four tool crates at 0.3.0 and glibc inputs at 0.1.0.
Provider startup/source inputs need the native build tools; link stubs are not a
replacement runtime. Provider-backed Python/shared-library support arrives in 0.1.1.

## Validation and limits

The original post-release record reports CI 12/12 and a crates.io installation
that built/ran a glibc 2.17 program on Ubuntu WSL. This backfill verified the
registry archive and tagged source, but did not recover/re-audit those original
CI artifacts or repeat the runtime checks. Earlier migration/provider results
in VALIDATION.md belong to their named revisions, not automatically this tag.
Real old-system tier 3 and arbitrary native dependency closure are not established.

The [history audit](https://github.com/rustcommons/cargo-libc/blob/main/docs/releases/HISTORY.md) records original registry dates,
archive checksums and bounded historical evidence gaps. No checks were fabricated
or tags moved during this documentation backfill.
