# cargo-libc 0.3.0

Ordinary calls to all five overlapping clock functions prefer libc while explicit legacy versions remain linkable.

Original crates.io publication: 2026-11-02 (UTC). Package `cargo-libc` 0.3.0
is available and non-yanked, checked 2026-11-02. Source tag `v0.3.0`:
`a70ce9ffac6be8611b66a2829fefb3093cb41ce6`.
These notes were reconstructed on 2026-11-02; their later GitHub publication date
is documentation backfill, not the original software release date. They were not
present at the historical tag and do not modify its package.

## Changes

- Prefer libc's GLIBC_2.17 defaults for `clock_gettime`, `clock_getres`,
  `clock_settime`, `clock_nanosleep` and `clock_getcpuclockid`, with no clock mode
  option. Producer-owned read-only RT overlays preserve explicit legacy versions,
  genuine RT APIs, original library order/groups and caller as-needed state.
- Validate selected provider/sysroot ELF inputs and effective named libraries;
  bounded standard sysroot scripts are supported, opaque bypasses refused.
- Include profile/input identity in generated configuration and relink fingerprints.
  Unwinder/libgcc_s and static-runtime policy are unchanged.

## Upgrade

Install `cargo-libc` 0.3.0 with `--locked` and regenerate complete saved shell/TOML
configuration. The root provider minimum/lock rises to `libc-abi-tools` 0.4.0;
kernel/scanner/targets stay locked 0.3.3, glibc inputs stay 0.1.2/0.1.1. The internal
profile fingerprint relinks an existing target directory without manual cleaning.
Custom opaque script/response or unproven fallback inputs may now refuse instead
of silently bypassing the profile. No provider-cache import is promised.

## Validation and limits

Rust 1.90 source/native/registry/package/install gates and Windows portable
checks passed at the exact refs in the detailed record. Native evidence includes
all five clocks, mixed legacy references, real RT APIs, GNU ld/LLD, same-directory
upgrade and 68 named-input acceptances. The Aero three-way comparison passed
182 behavior cases per Cargo variant; unchanged strict Zig comparison still fails
because libgcc_s and pre-existing non-clock differences remain. Published-install
run 41382187049 passed, including Docker/Podman streams. Container-provider clock
preparation, general dependency closure and actual old-system tier 3 remain
unqualified; prebuilt legal gates remain unchanged.
