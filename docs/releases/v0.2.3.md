## Changes

- Use absolute repository URLs for the packaged README's excluded guides/banner;
  add the maintained requirements/documentation index and consistent guidance.
- Adopt documentation-corrected `glibc-abilists` 0.1.2 and
  `glibc-provider-sources` 0.1.1 in the real registry lock. Their ABI/source payloads
  are unchanged; four tool packages stay 0.3.3 and direct floors are unchanged.
- No cargo-libc runtime/API behavior changes from 0.2.2.

## Upgrade

Install `cargo-libc` 0.2.3 with `--locked` for the corrected package documentation.
No runtime migration is needed. Historical 0.2.2 archives remain immutable.
This version's README still labels the 0.2.2 evidence link as “Current release”;
0.2.4 replaces that label with version-neutral release navigation.
